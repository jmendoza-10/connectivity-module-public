# WWAN carrier: KiCad 9 schematic, rev 0.3 (spin-1 bench prototype)

Hierarchical schematic: a root sheet plus 8 child sheets. It was generated by `hardware/generator/` (rev 0.1: `gen_v1/design.py`) from pin tables transcribed out of the datasheets.

- ERC (`kicad-cli sch erc --severity-all`, KiCad 9.0.2): 0 errors, 0 warnings.
- Netlist sanity (`../generator/netcheck.py`): PASS. 464 components.
- PDF: `../wwan-carrier-schematic-rev0.3.pdf`. Previews: `../diagrams/preview-{root,power-input,pcie,slot1,control}.png`.

## Rev 0.3 (2026-10-10): vendor-neutral WWAN slots, no Nexperia/PRC parts
Intentional netlist changes vs rev 0.2 (`cmpnet.py rev0.2_reference.net wwan-carrier.net` reports DIFFERENT; 452 -> 464 components):
- **Slot symbol** `M.2_KeyB_WWAN` (was FM350 pinout): generic pin names, vendor use in brackets (e.g. `GPIO5[IF_SEL]` pin 20,
  `GPIO6[VBUS_SNS]` pin 22, `GPIO8[PLA_S2#]` pin 28). Titles/values say "M.2 Key-B WWAN (EM9291/FN990)".
- **Pin 20 (host-interface select)**: open-drain 2N7002-class FET (Diodes 2N7002-7-F; not Nexperia) pulls pin 20 low = PCIe.
  Its gate is a **new expander line `SLOTn_PCIE_SEL`** (U802 P1.4-P1.6, ex-spares, 10k PU = PCIe default), not `SLOTn_PCIE_EN`,
  because pin 20 is sampled at card boot while PERST# must be released >= 150 ms after power-valid (EM92). DNP 10k pin 20 -> +1V8
  for Sierra USB mode (Telit has an internal 10k PU).
- **Pin 22**: DNP 10k to the slot rail +3V7_Sn (Sierra VBUS_SENSE, 1.6-5.25 V; slot rail avoids back-powering an unpowered card).
  Never fit with Telit (pin 22 is a 1.8 V GPIO). TP on pin 22 and pin 28.
- **Pins 24/38/68 NC** (Sierra optional VCC / Telit GPIO); **pin 73 -> GND** (EM92 GND; FN990 GND per HDG).
- **SLOTn_PCIE_EN default pull-down** (was pull-up): PERST# held low with the expander in reset. PCIE_EN now gates only PERST#.
- **Standoffs**: 3052 (H) and new 3042 (H42) positions per slot.
- **Nexperia removed**: Q101/Q102 -> onsemi NVMFS5C646NL (SO-8FL 488AA, `Package_SO:ONSemi_SO-8FL_488AA`); U302 74LVC1G07 -> TI
  SN74LVC1G07DCKR; slot AND gates TI SN74LVC1G08DCKR; 2N7002 -> Diodes 2N7002-7-F. Every R/C carries a named maker MPN
  (Yageo/Panasonic/Vishay resistors; Murata/TDK/KEMET caps), plus Murata, Lite-On, Kingbright, Littelfuse, Abracon, Samtec, Würth.
- GNSS / antennas: no carrier bias or LNA (see `docs/antenna-gnss-plan.md`); RF connectors are on the cards (pigtails).

## Rev 0.2 (2026-10-09): wired-schematic rework, same netlist
- **Drawn wires:** every local connection inside each sheet is now a drawn, orthogonal wire with junction dots and a left-to-right signal-flow layout. The previous version used net labels. There are no local or global net labels anywhere. Labels remain only as:
  - Hierarchical labels, for the inter-sheet signals.
  - Power symbols, for the rails (+12V, +3V3, +0V95, +1V8, +1V2, +3V7_S1..3, GND).
- **Root sheet (A1):** a wired block diagram. All 68 inter-sheet signals are hierarchical sheet pins connected by drawn wires, in ordered bundles:
  - PCIe switch -> slots 1-3, plus the PERST# fan-out.
  - USB5744 -> slots 1-3.
  - Slots -> control.
  - Control <-> wwan_power.
  - Power_input PGs -> control.
  - Control I2C -> PCIe switch and hub.
- **Sheet sizes:**
  - pcie_switch: A1.
  - All other sheets: A2.
- **Netlist equivalence** (`hardware/generator/cmpnet.py` against `hardware/generator/wwan_v1_reference.net`, the rev 0.1 export): EQUIVALENT.
  - 452 components, with the same refs and values.
  - Every net has an identical pin set.
  - Some local nets now carry KiCad auto-names (`Net-(...)`) instead of label names. Connectivity is unchanged. Check with `hardware/generator/cmpnet.py hardware/generator/wwan_v1_reference.net hardware/kicad/wwan-carrier.net`.
- **ERC** (`kicad-cli sch erc --severity-all`): 0 errors, 0 warnings.
- **BOM:** identical to rev 0.1.
- **Generator:** `hardware/generator/` is the layout-aware generator (rev 0.1 label-style generator in `hardware/generator/gen_v1/`).
  - `circuit.py`: the circuit. Same parts and nets as `gen_v1/design.py`.
  - `layout.py`: placement and explicit wiring.
  - `engine.py`: symbol builder, orthogonal router, and root block-diagram builder.
  - Regenerate with `tools/regen_hardware.sh` from the repo root (wraps `hardware/generator/build.py`, netlist/ERC/PDF/BOM export, netlist equivalence check and `tools/gen_interface.py`). The `.kicad_pro` file is kept in `hardware/kicad/` and is not regenerated.

## Footprints still to do
- **M.2 Key-B socket:** LOTES APCI0026-P001A (Taiwan). No KiCad footprint exists. Stack height vs EM9291/FN990 component height **VERIFY**. Needs both 3052 and 3042 standoff locations (H/H42 in the schematic).
- **LM61460-Q1:** TI RJR0014A VQFN-HR-14, 4x3.5 mm. Not in the KiCad libs (U102, U201-U203).
- **Verify against the vendor drawings:**
  - PI7C FCA144: the generic LFBGA-144 0.8 mm is assigned.
  - USB5744 EP size: QFN-56 7x7 EP5.6 is assigned.
  - LM74800 DRR WSON-12: the EP is RTN and must float.
- **PCIe x1 gold finger:** the stock BUS_PCIexpress_x1 is used. Board edge bevel and hard gold go in the fab notes.
