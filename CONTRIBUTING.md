# Keeping hardware and docs in sync

The schematic is **generated** (`hardware/generator/`), and several software artefacts are **generated from the schematic's
netlist**. Do not hand-edit generated files.

| File | Generated by | From |
|---|---|---|
| `hardware/kicad/*.kicad_sch`, `wwan_carrier.kicad_sym`, `sym-lib-table` | `hardware/generator/build.py` | `circuit.py` + `layout.py` |
| `hardware/kicad/wwan-carrier.net` | `kicad-cli sch export netlist` | schematic |
| `hardware/wwan-carrier-erc.rpt`, `-bom.csv`, `-schematic-rev0.2.pdf` | `kicad-cli` | schematic |
| `docs/hw-sw-interface.md` | `tools/gen_interface.py` | netlist + semantic tables in the script |
| `software/tools/carrier_map.json` | `tools/gen_interface.py` | same |
| `software/dts/carrier-gpio-line-names.dtsi` | `tools/gen_interface.py` | same |

## After any schematic change

```sh
tools/regen_hardware.sh      # needs KiCad 9 (kicad-cli) + python3; ~15 s
git diff --stat
```

The script rebuilds the schematic (fixed `PYTHONHASHSEED`, so output is reproducible), exports netlist/ERC/PDF/BOM, compares the
netlist with `hardware/generator/wwan_v1_reference.net`, and regenerates the interface files. Expect:

- `ERC messages: 0  Errors 0  Warnings 0`
- `RESULT: EQUIVALENT` - if the change is an intentional connectivity change, review the cmpnet output, then replace
  `wwan_v1_reference.net` with the new netlist in the same commit and say so in the commit message.
- The PDF always changes (embedded timestamp); everything else should only change where you changed the design.

If `gen_interface.py` aborts with "no SEMANTICS entry" or an alias mismatch, a pin on an expander changed: update `SEMANTICS` /
`PIN_ALIASES` in `tools/gen_interface.py` (meaning, polarity, safe initial value), then update `power-reset-sequencing.md` and
`carrierctl.py` if behaviour changed.

## Hand-written docs that must be reviewed on changes

- `docs/power-reset-sequencing.md` - if any slot control signal, pull resistor, or rail sequencing changes.
- `docs/linux-bringup.md`, `software/dts/frdm-imx95-wwan-carrier.dtso` - if I2C addresses, interrupt/reset wiring change.
- `docs/open-issues.md` - close items with evidence (link to test result), never just delete.

## CI

`.github/workflows/checks.yml` runs `tools/gen_interface.py --check` (fails if generated files are stale) and KiCad ERC in the
`kicad/kicad:9.0` container.

## Conventions

- Mark anything not confirmed by measurement or a primary source as **VERIFY** / **UNVERIFIED**, with the source you do have.
- Cite datasheets by document number and revision (e.g. Diodes DS43484 Rev 5-2, Microchip DS00001855J, TI SCPS194F, Sierra EM92XX PTS Rev 5, Telit FN990 HDG Rev 3).
- No credentials, SIM ICCIDs/IMSIs, or carrier account data in the repo.
